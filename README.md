# CaterEngine

The CaterEngine marketing and restaurant partner application site, built with
Next.js and ready to deploy on Vercel.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
npm install
npm run dev
npm run build
```

This starter does not use `wrangler.jsonc`.

## Useful commands

- `npm run dev`: start local development
- `npm run build`: create the production build
- `npm start`: run the production build

## Deploy

Push the repository to GitHub, then import it at Vercel. Vercel detects Next.js
automatically and does not require custom build settings.
